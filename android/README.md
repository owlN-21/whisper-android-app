## Audio Summary

Audio Summary Android — мобильное приложение для загрузки аудиофайлов и получения структурированных конспектов. Приложение работает совместно с main backend, который принимает аудио, запускает обработку через processing-service, сохраняет transcript и summary, а затем отдает результат Android-клиенту.

Приложение не выполняет распознавание речи и генерацию конспекта самостоятельно. Android-клиент отвечает за пользовательский интерфейс, загрузку файла, отслеживание статуса задачи, получение результата и локальное хранение истории.

Основной сценарий работы

Пользователь открывает приложение, вводит email и входит в аккаунт. Если пользователя с таким email нет на сервере, приложение автоматически создает нового пользователя.

После входа пользователь попадает на главный экран “Мои конспекты”, где отображается история обработок. Пользователь может выбрать аудиофайл формата mp3, wav или m4a, отправить его на backend и дождаться завершения обработки.

После завершения обработки приложение получает расшифровку и структурированный конспект, сохраняет их в локальную базу данных и открывает экран результата.

Основные возможности

В приложении реализовано:

* вход и автоматическая регистрация по email;
* сохранение пользовательской сессии;
* автоматический старт приложения по состоянию входа;
* выбор аудиофайла через системный проводник Android;
* поддержка mp3, wav и m4a;
* multipart-загрузка аудио на backend;
* отслеживание статуса обработки задачи;
* отображение этапов обработки: распознавание аудио и создание конспекта;
* получение transcript и summary после завершения обработки;
* локальное хранение задач, конспектов и расшифровок через Room;
* восстановление истории задач с backend после повторного входа;
* открытие готовых конспектов с главного экрана;
* удаление готовых конспектов;
* удаление ошибочных задач с главного экрана;
* проверка соединения с backend;
* выход из аккаунта.

Структура экранов

В приложении используются следующие основные экраны:

LoginScreen — экран входа и автоматической регистрации по email.

LoadingScreen — промежуточный экран, который проверяет сохраненную сессию пользователя.

MainScreen — главный экран приложения. Показывает историю обработок, готовые конспекты, ошибочные задачи и переход к загрузке нового аудио.

AudioUploadScreen — экран выбора аудиофайла, загрузки на backend и ожидания обработки.

ResultScreen — экран просмотра готового конспекта и расшифровки.

SettingsScreen — экран настроек, где отображается текущий пользователь, адрес backend, проверка соединения и выход из аккаунта.

### Архитектура приложения

Приложение построено на Kotlin и Jetpack Compose.

Используются:

* Jetpack Compose для UI;
* Navigation Compose для переходов между экранами;
* ViewModel и StateFlow для управления состоянием экранов;
* Retrofit и OkHttp для работы с backend API;
* DataStore Preferences для хранения пользовательской сессии;
* Room для локального хранения задач, summary и transcript;
* Coroutines для асинхронной работы.

Работа с backend

Android-приложение обращается к main backend по адресу:

[http://10.0.2.2:8080](http://10.0.2.2:8080)

Этот адрес используется для Android Emulator. Он указывает на локальный компьютер, где запущен backend.

Основные endpoint-ы, которые использует приложение:

``` 
GET /health — проверка доступности backend.

```
```
GET /api/v1/users/by-email — поиск пользователя по email.
```
```
POST /api/v1/users — создание пользователя.
```
```
GET /api/v1/users/{userId}/tasks — получение задач пользователя.
```
```
POST /api/v1/users/{userId}/tasks — загрузка аудиофайла.
```
```
GET /api/v1/tasks/{taskId} — получение статуса задачи.
```
```
GET /api/v1/tasks/{taskId}/transcript — получение расшифровки.
```
```
GET /api/v1/tasks/{taskId}/result — получение конспекта.
```
```
DELETE /api/v1/tasks/{taskId} — удаление задачи.
```
### Локальное хранение

Для локального хранения используется Room.

В базе есть три основные таблицы:

`tasks` — локальные задачи обработки аудио.

`summaries` — сохраненные конспекты.

`transcripts` — сохраненные расшифровки.

### Синхронизация с backend

При открытии MainScreen приложение загружает список задач пользователя с backend и синхронизирует его с локальной Room-базой.

Если задача уже есть локально, она не создается повторно. Если задача отсутствует, она добавляется в Room. Для готовых задач приложение дополнительно подтягивает summary и transcript, если их еще нет локально.

Удаленные на backend задачи после синхронизации не появляются обратно в приложении.

### Статусы задач

Приложение обрабатывает следующие статусы:

`TRANSCRIBING` — идет распознавание аудио.

`SUMMARIZING` — создается конспект.

`COMPLETED` — обработка завершена, результат готов.

`FAILED` — обработка завершилась с ошибкой.

На UI статусы отображаются в виде:

`Готово`

`Ошибка обработки`

`Распознается`

`Создается конспект`
